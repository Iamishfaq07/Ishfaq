About

Half offence, half classroom.

Sr. Application Security Engineer with 5+ years across application security, vulnerability management and offensive research. Currently at R1RCM, where I built and scaled the AppSec program from inception to 100% security coverage across 20+ engineering teams — SAST/DAST/SCA tooling, OWASP governance, and the automation to keep it running.

The work spans the full spectrum: manual web and API pentesting, CVE triage and remediation at volume, SOC 2 readiness, and AI/LLM security testing against the OWASP LLM Top 10 — prompt injection, data leakage, instruction override, model misuse.

Outside the day job I hunt bug bounties, build recon tooling (KashRecon), and write KashSec Academy — a free 26-path cybersecurity course from "what is a computer" to malware reverse engineering. Currently grinding toward OSCP.

When I'm not breaking things: LLMs and local inference on an RTX 3070 Ti, gaming, cars, and far too much consumer tech research.
